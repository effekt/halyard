# The name is `nubbin`, singular

This name was contested on the grounds that `nubbin.io` was an operating developer tool
addressing the same audience. That address resolves nowhere — it carries no nameserver
delegation, so no request to it reaches anything, and the domain itself is unregistered.
The whole argument for changing the name was a cost curve measured against that collision.

So the project is `nubbin`, and the scoped packages stay as published. The word is arbitrary
applied to a page builder, which is the tier of mark that can actually be defended, and the
registry position is held rather than hoped for: the npm organisation of that name carries the
scope, and two domains redirect to the canonical one.

Rejected: renaming, which loses its premise entirely once the other product is absent, and
whose own warning applies to any replacement — a name suggested by a model is one it will
suggest to whoever asks next, so the convergence that makes a name feel apt is what makes it
common. Rejected also: the plural. `@nubbins/core` is taken by a state library, at exactly the
coordinates the plural would need. Setting that aside, the word carries two senses and only the
weaker one pluralises: a very small piece is a thing there can be many of, while the central or
essential part of something is not, and the second sense is what `core` is named after.
